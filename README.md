# OJT Attendance Tracker

Offline Android attendance tracker for an OJT placement.

- Save daily time-in and time-out records
- Automatically calculate daily hours
- Track progress toward 1,800 hours
- View, edit, and delete records
- Export records as CSV text for sharing
- Store records locally on the phone

GitHub Actions builds a debug APK after each push to main. Download the artifact named `OJT-Attendance-Tracker-APK` from the Actions tab after a successful build.

Package: `com.laurence.ojtattendance`
Minimum Android: 6.0 (API 23)
